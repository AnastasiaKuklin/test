В рамках дисциплины "Разработка программных приложений" написана программа для анализ оценок студентов Факультета государственного сектора НГУЭУ.
В результате работы кода выводится результат в формате:

В исходном датасете содержалось {Оценка} оценок, из них {Оценка} оценок относятся к группе ПИ101
В датасете находятся оценки {Личный номер студента_количество} студентов со следующими личными номерами (по ПИ101): {Личный номер студента}, {Личный номер студента}
Используемые формы контроля: {Уровень контроля}, {Уровень контроля}
Данные представлены по следующим учебным годам: {Год}, {Год}

Есть возможность выбрать необходимую группу вместо ПИ101.
Обрабатываются ошибки.
